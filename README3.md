Prroject: CLI Expense Tracker

Objective: 

Core Financial Ledger Purpose: Construct a robust command-line interface application designed to capture, categorize, and archive personal monetary transactions locally.

Persistent Storage Architecture: Implement Python's standard csv module to serialize runtime data structures directly to disk, ensuring transaction history survives terminal closures and process restarts.

Data Parsing & Aggregation Engine: Parse multi-column row iterators dynamically, applying index enumeration for human-readable display formatting and computing cumulative summation across numerical data fields.

Input Validation & Fault Tolerance: Enforce strict type casting (float()) combined with conditional logic and try-except exception blocks to intercept missing files and malformed user entries gracefully.
